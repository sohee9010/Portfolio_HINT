## ⚙️ 기록 자동화 구조 (DAY 3)

노션에 정리한 내용을 HTML로 다시 옮겨 적던 **이중 기록**을 없애기 위해 만들었습니다.

```
Google Sheets 기록 웹앱 (Apps Script)
        │  [확정] 버튼
        ▼
GitHub API로 index.html에 카드 자동 커밋
        │
        ▼
GitHub Pages 자동 배포 → 1~2분 안에 사이트 반영
```

- 올리기 · 삭제는 비밀번호로 잠금
- 그래서 이 저장소의 `DAY n 카드 확정 / 삭제` 커밋은 자동화 웹앱이 만든 커밋입니다
