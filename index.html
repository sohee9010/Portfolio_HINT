DAY 111/02작성 완료

디지털 트레이닝 AI 활용

문제
빠르게 발전하는 생성형 AI를 과제와 업무에 제대로 활용하는 방법을 익히는 것
내가 한 일
Claude, Gemini, ChatGPT, Copilot 등 생성형 AI의 흐름을 살펴보고, 목차를 활용해 프롬프트를 구조화하는 방법을 실습했습니다. AI로 유튜브 영상을 분석하고, 음악을 만들고, 보고서를 제작했으며, 공공데이터포털·NKIS 국가정책연구포털·NCS에서 근거 자료를 찾는 방법도 익혔습니다.
사용 기술
Gemini, GPT, Claude, Napkin AI, 공공데이터포털
결과
영상 분석, 음악, 보고서 결과물을 AI와 함께 완성했습니다. 'AI 결과물은 초안이고, 최종 판단과 검증은 사람이 한다'는 활용 원칙을 세웠습니다.
DAY 211/03작성 완료

AI로 포트폴리오 허브와 자동차 게임 만들기

문제
AI와 함께 아이디어를 실제로 동작하는 웹 결과물로 옮기는 것. 나를 소개할 포트폴리오 허브와 자동차를 주제로 한 게임을 만드는 것이 목표였습니다.
내가 한 일
AI와 대화하며 포트폴리오 허브의 섹션 구성과 인터랙션(리본 배경, 흐르는 결과물 카드, 역량 원 반전)을 직접 다듬었습니다. 이어서 자동차 레이싱 게임 '날아라 슈퍼카'와, 자율주행차가 피할 수 없는 사고 앞에서 내리는 선택을 다룬 '자율주행 딜레마' 게임을 기획하고 만들었습니다.
사용 기술
Claude, HTML · CSS · JavaScript, WebGL
결과
포트폴리오 허브 한 페이지와 게임 두 편('날아라 슈퍼카', '자율주행 딜레마')을 완성해 바로 플레이할 수 있게 공개했습니다. AI에 맡기기만 하지 않고 원하는 모습을 구체적으로 요청하고 고쳐 가는 방법을 익혔습니다.
