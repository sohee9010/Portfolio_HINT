DAY 211/03작성 완료

AI로 포트폴리오 허브와 자동차 게임 만들기

문제
AI와 함께 아이디어를 실제로 동작하는 웹 결과물로 옮기는 것. 나를 소개할 포트폴리오 허브와 자동차를 주제로 한 게임을 만드는 것이 목표였습니다.
내가 한 일
AI와 대화하며 포트폴리오 허브의 섹션 구성과 인터랙션(리본 배경, 흐르는 결과물 카드, 역량 원 반전)을 직접 다듬었습니다. 이어서 자동차 레이싱 게임과, 자율주행차가 피할 수 없는 사고 앞에서 내리는 선택을 다룬 자율주행 딜레마 게임을 기획하고 만들었습니다.
사용 기술
Claude, HTML · CSS · JavaScript, WebGL
결과
포트폴리오 허브 한 페이지와 게임 두 편(레이싱, 자율주행 딜레마)을 완성했습니다. AI에 맡기기만 하지 않고 원하는 모습을 구체적으로 요청하고 고쳐 가는 방법을 익혔습니다.
